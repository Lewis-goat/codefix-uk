Sage / Breville Oracle Jet error codes

19 codes. The Oracle Jet has single ThermoJet heater plus heated group head; most codes are one of its temperature sensors, a water-level or flow fault, or the grinder.

The Oracle Jet has a different, shorter code table (E1 to E19) from the older Oracles.

How to read the stored error log

Open Settings on the touch screen, then About the Machine, then Software version. On that screen tap each bottom corner of the screen several times. Go back to About the Machine and a new Service center mode entry appears. Open it to view the error log.

Service menus are intended for technicians. Reading the log is harmless; do not change calibration values.
