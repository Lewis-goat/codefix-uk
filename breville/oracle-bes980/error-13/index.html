Sage / Breville Oracle Error 13: temperature sensor open circuit (not detected)

Error 13 means: Steam wand temperature sensor not detected at startup.

Short answer. The control board cannot read the steam wand temperature sensor (NTC). On this code the sensor reads as an open circuit: the wire has come off, the plug is loose or corroded, or the sensor itself has failed. Because it fails the self-test at power-on, the machine refuses to start until the sensor reads again.

How to fix Error 13

  1. Switch the machine off at the wall, wait 60 seconds and switch it back on. A one-off reading glitch clears; a real open circuit comes straight back.
  2. The NTC is inside the steam wand. Clean the wand tip thoroughly and check the wand is not kinked or twisted at its base. If the code persists, the wand assembly (with its sensor) is replaced as one part; it is a screwdriver job.
  3. Check for water where it should not be. Moisture on the board or in a connector reads as an open or short. Dry everything and look for the leak that caused it (usually a boiler o-ring or hose clip).
  4. If the code returns, replace the steam wand temperature sensor (NTC). On the Oracle it is a plug-in part; note which way the wires route before pulling the old one.
  5. Clear the stored error afterwards (see how to read the error log below) so you can tell whether it recurs.

When to stop and call a repairer

Stop and book service if you find a swollen or burnt component on the board, or if the sensor plugs are fine and a new sensor does not clear the code: that points at the control board.

What it costs

Parts: Genuine NTC sensor assemblies run about $25 to $95 depending on which sensor it is (steam wand and milk-jug sensors are the dear ones). O-ring kits are $10 to $20.

Service: Out-of-warranty Breville service quotes for internal faults are commonly $300 to $500, sometimes more, plus shipping. Independent espresso repair shops are usually cheaper for a sensor swap.

Worth repairing? Usually yes. A sensor plus o-rings is under $100 and 30 to 60 minutes. Only a dead control board makes the repair questionable on an older machine.

How to check the error log

Leave the machine plugged in but switched off. Press and hold 1 CUP, 2 CUP and POWER together for at least one second. After the long beep the LCD shows the firmware version (starts with "Fr"). Press the SELECT dial once to open Error Storage, then rotate it to step through errors 1 to 32 and the stored count for each. Scroll past error 32 to "ErSt" and hold SELECT for 3 seconds to clear the log.

Clear the log after a repair so you can tell whether the fault has really gone.

Error 13 during startup or during use?

Sage / Breville Oracles report Error 13 during the power-on self-test. That timing is a useful clue when narrowing the cause.

Can I keep using the machine with Error 13 showing?

Usually you can finish the drink you are making, but do not ignore it — the underlying fault rarely heals itself. Work through the cheap checks first.

Will Error 13 clear on its own?

Sometimes. Try the reset and cleaning steps first — they cost nothing and clear the milder cases. A code that returns within a day or two needs the parts fix.

How long does the repair take?

Thirty minutes to an hour if you are comfortable opening the case; budget an afternoon the first time.
