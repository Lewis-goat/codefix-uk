Jura Error 3: steam thermoblock sensor fault

Error 3 means: Steam thermoblock temperature too low or its NTC sensor failed.

Short answer. The steam side of the machine is not reporting temperature. Same causes as Error 1 but on the steam thermoblock: sensor, cable, or a machine that is too cold.
Part at faultsteam thermoblock NTC sensor
Severitymedium
DIY difficultyhard
When it appearsany

How to fix Error 3

  1. Warm the machine to room temperature and restart.
  2. Descale if it is due; heavy scale slows heating enough to trip the check on some firmware.
  3. Inside, inspect the steam thermoblock sensor cable for a break where it flexes and reseat its plug.
  4. Replace the NTC if the fault persists.

When to stop and call a repairer

Security screws and mains voltage inside; hand it over if that is not you.

What it costs

Parts: Genuine Jura NTC sensor about $25 to $40; thermal-fuse cord set $15 to $30; a thermoblock $90 to $180.

Service: Out-of-warranty manufacturer service for a super-automatic is typically $250 to $500 including return shipping; independent espresso repairers are usually cheaper for a single part.

Worth repairing? Yes.

Error 3 during startup or during use?

Juras report Error 3 any. That timing is a useful clue when narrowing the cause.

Can I keep using the machine with Error 3 showing?

Usually you can finish the drink you are making, but do not ignore it — the underlying fault rarely heals itself. Work through the cheap checks first.

Will Error 3 clear on its own?

Rarely. A reset or power cycle is worth one try, but Error 3 with a "hard" difficulty rating almost always means a failed component that has to be replaced.

How long does the repair take?

This one is a bench repair for most owners — the teardown, test and reassembly are the bulk of the work, not the part itself.
