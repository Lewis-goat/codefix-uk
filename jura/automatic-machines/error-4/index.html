Jura Error 4: steam thermoblock overheat

Error 4 means: Steam thermoblock overheating or a defective sensor.

Short answer. The steam thermoblock got hotter than the board expected. Either the sensor is under-reading (scale insulation, corroded contacts) or the power board did not cut the heater. Jura lists Errors 2 and 4 as the two most common repairs.
Part at faultsteam thermoblock NTC sensor / power board
Severityhigh
DIY difficultyhard
When it appearsany

How to fix Error 4

  1. Unplug and let the machine cool for an hour.
  2. Run a full descale. Scale on the thermoblock changes how quickly the sensor sees heat.
  3. Inspect the sensor cable and contacts for corrosion; replace the NTC.
  4. If it overheats again with a new sensor, the power board is not switching the heater off and must be replaced.

When to stop and call a repairer

A heater that will not switch off is a fire risk. Do not leave the machine powered unattended while this code is active.

What it costs

Parts: Genuine Jura NTC sensor about $25 to $40; thermal-fuse cord set $15 to $30; a thermoblock $90 to $180. Power board $120 to $250.

Service: Out-of-warranty manufacturer service for a super-automatic is typically $250 to $500 including return shipping; independent espresso repairers are usually cheaper for a single part.

Worth repairing? Sensor: yes. Power board on an old machine: get the quote first.
