GE Appliances dryer error codes

GE dryers show E-codes for thermistors, the door switch, the motor tachometer and the control panel. The same code can mean different things on different vintages; each page says which.

How to read the stored error log

On newer GE dryers (GTD/GFD 2016 on), with the dryer off, press and hold the Signal and Temp buttons for 5 seconds to enter service mode; the last stored error shows. On SmartHQ models the app lists stored codes. Unplugging for 5 minutes resets the board.

Service menus are intended for technicians. Reading the log is harmless; do not change calibration values.
